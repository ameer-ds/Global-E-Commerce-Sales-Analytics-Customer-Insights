# PowerBI Project 
# Global E-Commerce Sales Analytics & Customer Insights

## Project Overview

Developed an end-to-end e-commerce analytics solution to analyze sales performance, customer behavior, product performance, delivery efficiency, and revenue trends using **Python, SQL, and Power BI**.

## 🔄 Data Analytics Workflow

### 1. Data Preprocessing — Python

- Cleaned and preprocessed the raw e-commerce dataset using **Python, Pandas, and NumPy** 
- Handled missing values and data inconsistencies
- Standardized formatting and data types
- Created derived fields required for business analysis and reporting

### 2. Data Storage & Database — SQL

- Loaded the cleaned dataset into a **SQL database**
- Structured and managed the processed data for analytical reporting
- Established a connection between the **SQL database and Power BI**

### 3. Business Intelligence — Power BI

- Connected **Power BI** directly to the SQL database
- Developed **DAX measures** for key business KPIs
- Built a two-page interactive dashboard covering:
  - Sales and revenue performance
  - Monthly revenue trends
  - Product and category performance
  - Customer age-group analysis
  - Geographic sales analysis
  - Payment method analysis
  - Delivery performance
  - Customer rating analysis
- Added interactive **Year, Location, and Product Category slicers**
- Used **Key Influencers** to analyze factors associated with customer ratings
